# 🎥 ScreenFlow

ScreenFlow is a modern platform for capturing, managing, and sharing screen recordings with ease.

## ✨ Features

- Screen recording
- Video management
- Secure sharing
- Responsive design
- Fast and intuitive user experience

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/screenflow.git
cd screenflow
npm install
npm run dev
